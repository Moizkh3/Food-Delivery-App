# 🍽️ Food Delivery Web Application

![React](https://img.shields.io/badge/React-19.0.0-blue)
![Vite](https://img.shields.io/badge/Vite-6.3.1-purple)
![License](https://img.shields.io/badge/license-MIT-green)

A modern and responsive food delivery web application built with React and Vite. This project provides a seamless user experience for ordering food online, featuring a clean and intuitive interface.

## ✨ Features

- 🚀 Fast and responsive user interface
- 📱 Mobile-first design approach
- 🎯 Intuitive navigation and routing
- 🎨 Modern and clean UI design
- ⚡ Optimized performance with Vite
- 🔍 Smart search functionality
- 🛒 Easy-to-use shopping cart
- 📍 Location-based restaurant suggestions

## 🛠️ Tech Stack

- **Frontend Framework:** React 19
- **Build Tool:** Vite 6
- **Routing:** React Router DOM 7
- **Code Quality:** ESLint
- **Language:** JavaScript (ES6+)

## 🚀 Getting Started

### Prerequisites

- Node.js (v14.0.0 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/Moizkh3/food-delivery.git
```

2. Navigate to the project directory
```bash
cd food-delivery/frontend
```

3. Install dependencies
```bash
npm install
# or
yarn install
```

4. Start the development server
```bash
npm run dev
# or
yarn dev
```

5. Open your browser and visit `http://localhost:5173`

## 📦 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
